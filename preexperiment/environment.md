# 基础验证环境

本目录用于预实验准备，不修改 `../rtl/` 中的用户源文件。

## 有状态模块

- 只有 `clock` 一个采样时钟，按上升沿离散采样。
- 第一个采样沿要求 `reset=1`，建立复位状态；之后复位可以在采样沿重新断言。
- 复位期间禁用目标检查。单周期后继性质也在前一采样沿复位时禁用。
- 输入数据、valid、ready、实体与标签均未添加协议假设。性质只声称记录的局部关系，不声称输入遵守完整 AXI/CHI 协议。
- `ENABLE_INITIAL_REG_` 未定义。未复位的数据寄存器和 RAM 保持任意初值，不能借助全零初始化证明性质。
- Yosys 的 `async2sync` 用于周期模型转换；本次结果不覆盖采样沿之间的异步复位脉冲、毛刺或模拟时序。
- “next” 对应 `|=>`，后继中的 `$past` 和 `$stable` 在后继采样沿解释；“overlap” 对应 `|->`。

## 组合模块

`PriorityEncoderOneHotLow8` 不含时钟或复位，所有 8 位输入组合均允许。
生成的检查器使用组合立即断言，SAT 直接检查所有输入组合。
原始编码器完整的 `priority if ... else` 链在 Yosys 查询副本中去掉 `priority` 限定词，
以兼容其前端；保留完整分支、优先顺序和最终 `else`。原始文件、冻结副本及供其他工具使用的断言均不改写。

## 证明与覆盖的含义

`scripts/check.py` 只降低本数据集的组合、同周期和单周期后继断言，生成观察性监视逻辑；不实现通用 SVA 翻译。
有状态参考性质要求时间归纳成功，组合参考性质要求组合 SAT 证明成功。
错误 RTL 在默认 16 步内查找违反同一参考检查的反例；未找到反例应记为未解决，不应记为等价或正确。
触发覆盖单独运行，不把目标断言转换成假设；后继检查的覆盖要求观察到未被复位取消的后继检查。
每条目标独立检查，不把其他目标假设为真，也不依赖未经证明的辅助引理。
`Q6_03` 的数据保持检查显式联合证明两个指针的范围不变量；这些不变量也是 `Q6_05` 的独立目标，
没有将其写成环境假设。该加强用于排除归纳步中不可达的非法指针状态，目标性质保持不变。

另建立共享输入的原版/错误版组合进行接口比较。队列的无效输出数据不参与比较，
仲裁器只在双方输出有效时比较事务 ID；ready/valid 控制输出始终比较。
接口差异反例是变异不等价的单独证据，不依赖参考断言的语义翻译。

原始 RTL 中没有独立自然语言规格。本目录的 `contract` 是依据 RTL 整理的候选局部行为契约，
其来源统一标为 `rtl_derived_candidate_contract`。工具通过不代表它已得到独立规格认证。
